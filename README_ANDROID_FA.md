# جریان ایرانی Pro Android

این ساختار برای ساخت APK با GitHub Actions است. رابط HTML در assets قرار گرفته. هنوز اتصال موتور FastAPI به Android WebView (loopback/local server و ارتباط lifecycle) تکمیل نشده؛ بنابراین APK ساخته‌شده در این مرحله پوسته‌ای خواهد بود و APIهای رابط را اجرا نمی‌کند. این محدودیت صریح است.
